第 06 课

云电脑、连接器、本机执行

工位在云端。你负责登录、验证码和支付；Bot 负责把活做完。

Grok Bot 从一台持久云电脑干活：浏览器、命令行、文件、连接器。不依赖你的笔记本一直开着。

看它在干什么

从对话打开 Agent Computer，预览点击、输入、导航和当前状态。可以离开预览，工作继续。关掉 Grok Bot 或合上笔记本，云端工作不停。详情面板里的实时预览点一下可全屏。

敏感步骤：人来接管

密码 / passkey、两步验证、CAPTCHA、支付或身份核验、以及明确要求真人的网站——这些该你来。

  1. 打开 Agent Computer。
  2. 接管（take control）。
  3. 只完成被挡住的那一步。
  4. 交还控制，让 Bot 继续。

不要贴进普通聊天

不要把密码或一次性验证码粘贴到对话里。若连接器弹出 secure secret request：在那里填。值会被遮罩，不进文字记录，也不展示给模型。它不是通用密码管理器。

浏览器会话会留下来，通常不必每个任务都登录。因为浏览器是共享的，给一个 Bot 登录，其他 Bot 在合适时也能用这个会话。有的网站会过期或再验一次：让 Bot 停下并通知你，而不是绕过检查。

连接器 Connectors（界面里叫 Plugins）

  1. 打开 Settings → Plugins。
  2. 在 Marketplace 浏览连接器和打包 Skill。
  3. 选 Add。
  4. 若需要，在浏览器完成授权。装上了仍可能要再认证一次。
  5. 聊天里用 @ 把连接器附到任务上；用 / 引用 Skill。

有连接器就优先用连接器，通常比在网页上点来点去稳。没有连接器、或需要连接器暴露不了的视觉流程，再用浏览器。已安装连接器是账号级的，不隔离到某一个 Bot。团队插件可能被管理员要求或限制，以你当前版本界面为准。

私有 Skill 若没出现在 / 菜单：到 Settings → Plugins → Yours，为当前 Bot 启用。

文件

电脑上有共享工作区 /workspace。让 Bot 把要留着的项目文件放那里，并用清楚的项目文件夹。文件、浏览器状态和支持的登录，按设计能挺过常规的电脑更新与恢复。临时目录、手动装的软件、未提交的应用状态，当作可丢的。重要结果复制进共享工作区，或附到对话里。

本教程不展示任何私人路径或公司目录名。

更新、恢复、重置云电脑

电脑不可达时，从错误状态用 Recover computer（若提供）。计划中的维护或最后手段，打开设置里的 Updates 或 Beta 区域（名称以你当前版本界面为准）：

  • Update Agent Computer：按钮是 Update，再点一次 Click Again to Confirm。换一台新实例，保留文件和登录；手动安装的软件要重装。优先用这个。
  • Recover Agent Computer：在提供该动作时，替换不可达的电脑并尽量保留持久状态。
  • Reset Agent Computer：最后手段，回到最近的持久快照，可能丢掉最近未同步的工作。

这三件事都不是 Check for Updates。后者更新的是 Grok Bot App。可能的话等正在进行的工作结束再恢复。更稳妥的顺序见官方 Troubleshooting；细节以当前文档为准。

本机执行是另一回事

云电脑和你面前的 Mac / Windows 不是同一台机器。Bot 只有在本机执行能力打开、并且通过你的本机策略批准后，才会在你的电脑上跑命令。

路径：Settings → General → Agent → Execution on Local Computer

  • Ask every time（默认）
  • always allow
  • never allowed

建议：没有明确理由就选 Never allowed。 这项不阻止 Bot 使用云电脑。组织管理员可能限制本机执行。Auto-review 规则存在当前桌面并同步到它的 Grok Bot 电脑；不要假设另一台桌面安装有同一套规则。
