FAQ 和一页小抄

卡住先看这一页。按钮文案若对不上，以你当前版本界面为准，并打开官方文档。

FAQ

在哪跟 Grok Bot 说话？

macOS / Windows 桌面 App，或 iOS 伴侣 App。同一批 Bot 和对话会在已登录设备间同步。

合上笔记本它还干活吗？

会。工作在云电脑上。关 App、合笔记本、锁屏 iPhone，都不会停掉后台回合或 Routine。

我的 Bot 共用一台电脑吗？

是。每个 Bot 用同一台持久云电脑，共享文件、浏览器会话和登录。电脑按用户分配，不按 Bot。不要把分开的 Bot 当安全边界。

几个 Bot 能同时干活吗？

能。它们可以并行推理、用连接器、处理文件、互相协调。每个 Bot 有自己的屏幕；一个 Bot 在自己的屏幕上一次只能跑一个电脑操作任务。

Bot 记得什么？

稳定偏好、角色上下文、先前工作的摘要。对话和学到的角色与其他 Bot 分开；共享文件、浏览器会话、群消息和直接交接可以在它们之间搬上下文。重大决策请它查当前源，不要只靠记忆。

能用任意网站吗？

许多基于浏览器的工具可以，包括没有专用连接器的服务。站点仍可能拦截自动化、要求重新登录、弹出 CAPTCHA 或要真人确认。这些步骤应交给你，而不是绕过。有连接器就优先用连接器。

哪些动作需要我审批？

取决于工具、动作风险，以及（若已启用）你的 Auto-review 规则。敏感或重大动作会停下。密码、两步验证、CAPTCHA 等走电脑接管。把长期边界写进 Bot description，并为发送、发布、删除、购买、改生产加上窄的 Require Approval 规则。

数据和隐私？

使用 Cursor 认证和账号数据设置。训练退出遵循适用的 Cursor 设置。需要云存储，不支持 Legacy Privacy Mode。所有 Bot 都能访问分配给你账号的那台云电脑。细节见官方 Approvals, security, and privacy。

多少钱？

视账号和套餐而定。合格套餐：SuperGrok Plus / Heavy，Cursor Pro+ / Ultra，Cursor Teams Standard / Premium。订阅含每周用量；符合条件的账号可加按需用量（按模型和 token 成本计）。同时有 Cursor 和 SuperGrok 时，用用量更多的那一份。以 x.ai/bot 或 Cursor 定价为准。企业客户联系 Cursor 客户团队。这里不编造价格。

团队和企业能用吗？

自助的 Cursor Teams Standard 和 Premium 席位包含 Grok Bot。企业访问在逐步开放。可用性与管理控件因组织而异。

支持哪些平台？

macOS Apple silicon 与 Intel；Windows x64 与 Arm64；iPhone iOS 18+。Linux 桌面、Android、iPad 在初始发布时不支持。

Skill 和 Routine 有什么差别？

Skill 描述怎么做。Routine 把流程交给某一个 Bot，并告诉它何时跑（日程或事件）。先在一次性真任务上测 Skill，再变成 Routine。

能演示给 Bot 看吗？

当 Teach a task 可用时，从电脑画面录一段浏览器流程，Bot 会做成草稿 Skill 供你审和测。可能分批开放，录制上限约十分钟，不录麦克风。没有入口就请 Bot 根据刚做完的任务保存 Skill。

能分享 Bot 吗？

能。复制公开链接。对方在 x.ai 预览并添加副本。他们得不到你的电脑、登录或聊天。链接会暴露配置，先去掉秘密。加入即接受第三方 bot 条款。

删除 Bot 会怎样？

去掉该 Bot 的 profile、对话和 routines。因为电脑是共享的，文件和登录可能还在。以后可能还要用，就 Hide。

一页小抄

打开什么

设置：左下角账号按钮，或 Cmd/Ctrl+,，或命令面板 Open settings。

Bot 面板：点标题名字，或 Cmd+Shift+I，或 View conversation details。

新建：Cmd/Ctrl+N → Create new agent。

五件套

Outcome · Sources · Constraints · Deliverable · Review。你决策，Bot 执行。

Composer

@ Bot / 群 / Routine / 连接器。 / Skill。

电脑

全体 Bot 一台云电脑。屏幕分开，登录不分家。Update Agent Computer 优先于 Reset。Check for Updates 只更新 App。本机执行默认 Ask every time，建议 Never allowed。

Skill / Routine

Skill = 怎么做。Routine = 哪个 Bot + 何时。Test run 是真干活。每 Bot 50 条 Routine，保留 20 次运行。删 Bot 会删它的 Routine。Hide 不会暂停 Routine。

必须审批

发送 · 发布 · 删除 · 购买 · 改生产。Require Approval 压过 Always Allow。审批不撤销已完成工作。密码走接管，不进聊天。

编制

一个稳定岗位一个 Bot。群聊只为可见交接。上限 50（Bot + 群聊）。分享是配置副本，先去掉秘密。
