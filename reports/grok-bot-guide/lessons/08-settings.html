第 08 课

设置在左下角，不在菜单栏

账号按钮、逗号快捷键、命令面板。分区因账号而异，看得到什么就用什么。

App 级和桌面本地行为在 Settings；某一个 Bot 的档案和通知在 conversation details。

怎么打开设置

  • 侧边栏左下角账号按钮（头像 + 账号名）→ Settings
  • Cmd/Ctrl+,
  • 命令面板输入 Open settings

没有这些入口

没有 macOS「系统设置 / Preferences」菜单项，也没有菜单栏齿轮。分区因账号和推送而异，有的选项可能不出现。以你当前版本界面为准。

General

Account

Sign In with Cursor / Sign Out。账号菜单还可能显示 About、已安装 Grok Bot 版本、iOS App 链接。

Appearance

Follow System / Light / Dark。

Agent

  • Default Model（若提供模型选择）
  • Timezone：Routine 按此时区跑日程
  • Execution on Local Computer：Ask every time / always allow / never allowed。建议无理由则 Never allowed。只约束你面前这台电脑，不挡住云电脑。
  • Auto-review 与个人审批规则。Require Approval 永远压过 Always Allow。下一课细讲。

本机执行和 Auto-review 是当前这套桌面安装的设置，不是「所有设备自动同一套政策」。换一台电脑要再确认。

Plugins

Marketplace 发现连接器和打包 Skill；Yours 查看已装插件和私有 Skill。已装连接器仍可能要在浏览器里授权。连接器工具可逐个开或关。若 Skill 不在 / 菜单里，到 Yours 为当前 Bot 启用。

Usage & Billing

出现时会显示每周包含用量，以及符合条件的非企业账号的按需用量。账号菜单也可能显示 Weekly usage。两处都没有，就去 Cursor 账号页或问组织管理员。价格以官方当前条款为准，这里不编造数字。同时有 Cursor 和 SuperGrok 时，用用量更多的那一份。

Team Setup

团队成员可能看到 Team Setup。管理员可提供在指定 Grok Bot 电脑上跑的托管设置；成员可查看或重装当前设置。不要把密钥直接写进托管设置说明。 没有看到该分区就跳过，以你当前版本界面为准。

Updates 或 Beta

这块可能叫 Updates，也可能叫 Beta。常见动作：

  • Check for Updates 或 Restart to Update：更新 App
  • Update Agent Computer：更新共享云电脑（保留持久状态；手动安装的软件要重装）
  • Reset Agent Computer：最后手段，可能丢掉最近未同步工作
  • 若提供：安全密钥或出口路由等选项

App 更新和云电脑更新是两件事。需要时还可能看到 Recover Agent Computer。

某一个 Bot 的设置

View conversation details → Agent settings：名字、title、description、头像、该 Bot 的通知偏好。群聊没有同样的逐 Bot 通知开关。

侧边栏状态

  • Needs attention：问题、审批、交接
  • Unread：新结果
  • Working / typing：进行中

打开对话会把当前活动标为已读。也可用 Bot 菜单手动标已读 / 未读。

通知

在该 Bot 的 Agent settings 打开 Notifications 后，完成或需要你输入时会发操作系统或手机通知。Grok Bot 处于前台焦点时，通知通常被抑制；侧边栏和 Dock 角标仍会亮。iPhone 首次运行会要通知权限；设备权限和 Bot 通知开关都得允许。移动推送可能仍在分批开放，以你当前版本为准。应用内错误出现在 composer 上方的 Notifications：可关掉一条或清空列表；有的带 Copy request ID，把完整 ID 发给支持。清空通知不会撤销外部动作，也不会删 Bot 历史。
