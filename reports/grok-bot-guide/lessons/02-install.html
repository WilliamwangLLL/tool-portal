第 02 课

先把工位打开

下载桌面 App，用 Cursor 登录。云电脑在云端，你的笔记本只是遥控器。

你需要三样东西：合格套餐、桌面 App、以及一件 Bot 能在真实应用或网站里完成的事。

平台

可以现在不行
macOS：Apple silicon 与 IntelLinux 桌面
Windows：x64 与 Arm64Android
iPhone：iOS 18 及以上（伴侣 App）iPad

同一批 Bot 会在已登录设备间同步。工作跑在云电脑上：合上笔记本、关掉 App 或 iPhone，后台任务和 Routine 不会因此停下。

谁能用

用 Cursor 账号登录。合格套餐包括：SuperGrok Plus / Heavy，Cursor Pro+ / Ultra，Cursor Teams Standard / Premium。套餐含每周用量；符合条件的账号可以打开按需用量。如果同时有 Cursor 和 SuperGrok，Grok Bot 会用用量更多的那一份。价格和条款会变，这里不写数字——看 x.ai/bot 或 Cursor 定价页。

Grok Bot 需要云端数据存储。Legacy Privacy Mode 不受支持。若账号还在旧隐私模式，需先改到 Cursor 支持的数据设置，Grok Bot 才能启动。企业可用性与管理控件因组织而异，以你当前版本界面和账号团队说明为准。

安装桌面 App

打开 https://x.ai/bot，选对应安装包。

macOS

  1. 选 Apple silicon 或 Intel 下载。判断方法：苹果菜单 → 关于本机。有 Chip 字段是 Apple silicon，有 Processor 字段是 Intel。
  2. 打开磁盘映像，把 Grok Bot 拖进 Applications。
  3. 打开 App。若系统询问确认，选 Open。

Windows

  1. 选 x64 或 Arm64。判断方法：设置 → 系统 → 关于 → 系统类型。
  2. 运行安装程序。
  3. 从开始菜单打开 Grok Bot。

App 会自动检查更新。也可以在设置里的 Updates 或 Beta 区域选 Check for Updates（更新的是 App 本身，不是云电脑）。区域名称以你当前版本界面为准。

登录

  1. 欢迎屏选 Get started。若已在 App 内：打开设置，选 Sign In with Cursor。
  2. 在弹出的浏览器里完成认证。
  3. 浏览器确认后回到 Grok Bot。

组织若要求 SSO，走平时的组织登录即可。设置怎么打开见第 08 课：侧边栏左下角账号按钮（头像 + 账号名），或 Cmd/Ctrl+,，或命令面板搜 Open settings。没有 macOS「系统设置 / Preferences」菜单项，也没有菜单栏齿轮。

第一次打开会问工具

Grok Bot 会介绍 Bot、共享电脑和 Routine，然后问你常用哪些工具。这些回答只用来塑造第一批同事建议，并不会连接或改动那些工具。云电脑在后台准备，最后一步进入 Meet a future teammate。
