第 05 课

创建、钉住、藏起、复制、分享、删除

这些动作都在侧边栏和 Bot 面板里，不在 Settings。删错没有后悔药。

这一课是侧边栏动作说明书。删除是永久的；不确定就先 Hide。

看一个 Bot 的详情

点聊天标题里的 Bot 名字，或按 Cmd+Shift+I，或选 View conversation details。用 X 关闭。

面板里通常有：实时电脑预览（点一下可全屏）、Routines、Channels、群成员。齿轮 / Agent settings：头像、名字、title、description、该 Bot 的通知。具体分区以你当前版本界面为准。

创建

  1. 侧边栏 New 或 Cmd/Ctrl+N。
  2. 选 Create new agent。
  3. 打开的是 New Agent。用 Bot actions → Edit Profile 改名字、title、description、头像。

上限：50 个 Bot + 群聊合计。

编辑

从 Bot 菜单改名字或描述。发现一条应长期有效的偏好、边界或职责，写进 description，不要只留在某一条消息里。

固定 Pin

把活跃的 Bot 钉在侧边栏顶部，方便每天找。

隐藏 Hide

  • Hide from sidebar：从主列表拿掉，不删除工作。
  • 侧边栏底部 Show hidden chats → Unhide 可恢复。
  • 隐藏不会暂停 Bot，也不会暂停它的 Routines。

复制 Duplicate

适合「同一角色、不同范围」，例如每个地区一个 Account Health Bot。副本名称形如原名 + copy，会带上：profile、settings、已启用 skills、routines、头像。 不会复制：聊天历史、学到的 memory、附件。先改名、写清新范围，再派活。

分享 Share

  1. 打开该 Bot，复制公开分享链接。
  2. 对方在 x.ai 预览，选 Add to Grok Bot。
  3. 需要有 Grok Bot App 才能加完。

分享前先扫一遍

链接是公开的。拿到链接的人能看到被分享的配置：身份、描述、skills、routines。先去掉 API key、内部 URL、客户数据和任何你不会写进公开文档的东西。对方得到的是配置的副本，不是你的电脑、登录或聊天记录。共享 Bot 由其他用户创建，加入即接受第三方 bot 条款。

删除 Delete

  1. 在侧边栏对该 Bot 右键 → Delete，再确认。
  2. 不在 Settings 里。不要翻设置找删除。

永久去掉：profile、对话、routines。共享电脑上的文件和登录可能还在。以后可能还要用，就 Hide，别 Delete。后端保留遵循适用的 Cursor 条款。

它记得什么

Bot 可以留下稳定偏好、重要事实和工作摘要，这样不必重放每一条旧消息。记忆替代不了权威数据源：变动的事实放在源系统；重大决策让它引用或重新打开当前数据；过期假设直接纠正；安全边界写进 description。
