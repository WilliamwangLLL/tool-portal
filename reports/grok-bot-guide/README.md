# Grok Bot 中文教程

一份可离线打开、可转发给朋友的静态教程：从安装 Grok Bot，走到第一个 Routine。

Grok Bot 是 xAI / Cursor 的桌面产品（另有 iOS 伴侣 App）：持久、有名字的 AI 同事，在共享云电脑上做真实工作。它不是 grok.com 的聊天窗口。

## 怎么打开

用浏览器打开本目录中的 index.html。不需要服务器。

macOS / Windows / Linux 均可双击打开。有网络时加载 Google Fonts；离线回退系统中文字体。勾选记录在本机浏览器。

## 打包发给朋友

把整个 grok-bot-guide 文件夹压缩成 zip 再发送。不要只发单独的 index.html，否则样式和插图会丢失。对方解压后同样打开 index.html。

## 可选静态托管

GitHub Pages、Cloudflare Pages、Netlify 或任何静态空间均可。站点根目录对准本文件夹，保持相对路径不变。无需构建。
