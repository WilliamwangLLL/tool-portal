# huacai-admin

华彩同城 · 运营后台前端（纯静态 HTML + Vanilla JS，无构建）。

## 现役入口与边界

- 生产前端：<https://www.haoyunlai.fun/huacai-admin/>
- 生产 API：同域 `/huacai-api`，由 Nginx 反向代理。
- 本目录只包含前端，不包含后端源码、管理员账号或密码。
- 不存在应继续使用的默认管理员凭据。创建、轮换或撤销账号时，以现役后端项目的运维文档和真实配置为准，不在本仓库保存示例密码。

## 本地预览

```bash
cd huacai-admin
python3 -m http.server 8888
# 访问 http://127.0.0.1:8888
```

在 `localhost`、`127.0.0.1` 或 `file:` 下，前端会请求 `http://127.0.0.1:3000/api`，因此联调前必须先确认对应后端确实在本机运行。生产环境自动使用同域 `/huacai-api`。

`tool-portal` 的 `deploy/deploy-production.sh` 只发布工具箱 V2 控制服务，不会同步本静态目录。修改本页面后，需先核对生产 Nginx 的 `/huacai-admin/` 真实文件来源和对应发布流程，不能把 V2 控制服务退出码当成该前端已上线的证据。

## 功能

- 📊 数据概览：用户/俱乐部/活动/订单/交易额/待处理
- 🏢 俱乐部审核：入驻申请通过/驳回
- 🎯 活动审核：主理人提交的活动审核（草稿/待审/已发/已结/已取消切换）
- 💰 提现审批：打款 + 记录转账单号；拒绝时自动退款到余额

## 安全建议

1. 管理员密码必须使用现役后端的安全命令轮换，不复用演示密码。
2. 验证 HTTPS、API 鉴权、登录失败限制和必要的访问白名单。
3. 对导出链接中的令牌暴露、浏览器存储和日志留存做定期审计。
4. 需要更高保护时增加二次验证。
